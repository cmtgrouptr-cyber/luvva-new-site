LUVVA Secure Gateway V39

- Temporary access restrictions disabled until Dashboard and central identity database are ready.
- Clears old local provider/device blocks automatically.
- All verified identities may receive a fresh 25-minute session during this development stage.
- Added a visible rotating refresh/reset command in the WhatsApp form: "Use another number".
- The reset command clears the typed phone/code and allows correction or entry of another real number.
- Final restriction model remains identity-based (email/phone/account ID), never device-wide or provider-button-wide.
- Permanent/admin/investor access codes will be managed from Dashboard in the final server-backed version.
