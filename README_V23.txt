LUVVA Secure Gateway V23 — Real Browser Data Test

Included:
- Persistent visitor log in localStorage (same browser/domain).
- Records identity, login method, entry time, session expiry, status, browser, platform, language and screen size.
- Does NOT store passwords or WhatsApp verification codes.
- 45-minute session and 5-minute notice retained.
- visitor-dashboard.html displays records, filters them and exports CSV.

Test:
1. Open index.html and complete a login.
2. After the welcome screen, open visitor-dashboard.html in the same browser/domain.
3. The visit record will appear.

Important:
This is real local browser data for prototype testing. Google/Facebook/LinkedIn/WhatsApp authentication and cross-device data require official provider credentials plus a secure online database/API.
