# LUVVA Website

A fast, responsive static website prepared for direct deployment to GitHub and Vercel.

## Upload to GitHub

1. Open the new GitHub repository.
2. Choose **uploading an existing file**.
3. Extract `luvva-website.zip` on your device.
4. Select everything *inside* the extracted `luvva-website` folder:
   - `index.html`
   - `style.css`
   - `script.js`
   - `assets` folder
   - `README.md`
5. Upload, then press **Commit changes**.

## Deploy on Vercel

1. Open Vercel and choose **Add New → Project**.
2. Import the `luvva-website` GitHub repository.
3. Framework Preset: **Other**
4. Root Directory: leave blank.
5. Build Command: leave blank.
6. Output Directory: leave blank.
7. Press **Deploy**.

## Important

Replace `partnership@luvva.tech` in `index.html` if a different email address is required.
